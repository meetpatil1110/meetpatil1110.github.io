Featured project

Autonomous Research Agent

An AI agent that breaks a research question into sub-tasks, picks its own tools (web search, a sandboxed calculator) and re-plans when the evidence is thin. Semantic memory skips repeat searches, and every claim in the final report traces back to its source.

  • LangGraph
  • Groq
  • FastAPI
  • ChromaDB
  • Docker
  • GitHub Actions

Streams every step live over SSE · deployed on Render behind a 45-test CI gate
